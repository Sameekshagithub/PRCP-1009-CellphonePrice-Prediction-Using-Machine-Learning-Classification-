## What this is

Bob has started a mobile phone company and needs to know what **price range**
(Low / Medium / High / Very High) a new phone should fall into, based purely on its
specifications (RAM, battery, camera, screen, etc.). This project:

1. Loads and validates the dataset
2. Runs a full Exploratory Data Analysis (EDA)
3. Trains and compares six classification algorithms
4. Picks the best model and explains feature importance
5. Serves predictions through a Flask web app with a dark-blue & white UI

## Setup (VS Code)

1. Open this folder in VS Code.
2. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS / Linux
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Make sure `data/train.csv` is present (the Kaggle "Mobile Price Classification"
   dataset — same file as `datasets_11167_15520_train.csv`).

## Run the full pipeline (from scratch)

```bash
python main.py
```

This will, in order:
- Load the data and print basic checks (shape, dtypes, missing values, duplicates)
- Run EDA and save every chart to `outputs/eda/`
- Split and scale the data
- Train Logistic Regression, Decision Tree, Random Forest, KNN, SVM, and Gradient
  Boosting — each printing its own accuracy/precision/recall/F1 and a saved confusion
  matrix under `outputs/confusion_matrices/`
- Compare all models (`outputs/model_comparison.csv` + `.png`) and pick the best one
- Plot feature importance (`outputs/feature_importance.png`)
- Save the best model as `models/model_bundle.pkl` for the Flask app

## Run the web app

```bash
cd frontend
python app.py
```

Open **http://127.0.0.1:5000** in your browser. Fill in the phone's specifications and
click **Predict Price Range** to get a result.

## Notes

- Each classifier lives in its own function in `src/train_models.py`
  (`train_logistic_regression`, `train_decision_tree`, `train_random_forest`,
  `train_knn`, `train_svm`, `train_gradient_boosting`) so you can run, tweak, or debug
  any single model independently.
- `main.py` is the single entry point that ties every step together — run it whenever
  you want to retrain from scratch (e.g. after updating `data/train.csv`).
